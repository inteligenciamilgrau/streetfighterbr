# Street Fighter BR

Protótipo web estático de luta arcade com:

- 5 personagens jogáveis, um por região do Brasil.
- Chefão final com cenário próprio.
- Cenários, abertura, mapa e sprite sheets gerados com `image_gen`.
- Soco, chute, pulo e especial para cada lutador.
- Música procedural diferente por ambiente e efeitos sonoros via Web Audio.
- Tela de configuração para volume de música e efeitos.

Abra `index.html` no navegador ou sirva a pasta localmente.

Controles:

- `A` / `D`: mover
- `W`: pular
- `J`: soco
- `K`: chute
- `L`: especial
- `Esc`: config
